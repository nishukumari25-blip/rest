# 🍽️ Savoré – Restaurant & Grill

## 📌 Project Overview

Savoré is a modern and elegant restaurant website designed to provide users with a smooth and visually appealing dining experience.

The website was developed by recreating the provided reference UI while focusing on responsive design, clean code, and functional interactions.

## ✨ Features

- Fully responsive design
- Desktop, tablet, and mobile support
- Responsive navigation with hamburger menu
- Hero section with call-to-action buttons
- About / Our Story section
- Interactive menu category filtering
- Food menu cards with pricing
- Reservation form
- Client-side form validation
- Reservation success message
- Smooth scrolling navigation
- Hover effects and interactive UI elements
- Local image assets
- Clean and semantic HTML structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Git & GitHub
